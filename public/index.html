🎬 字幕校时工作台

① 导入转写与切点

JSON 格式：{"words":[{"text":"词","start_ms":0,"end_ms":500}],"cuts":[6000]}。 时间无效或倒序/重叠的词段会被拒绝。

② 排版规则

保存后点「重新排版」生效。版本号防止并发覆盖：过期提交会被拒绝并返回当前内容。

③ 排版

锁定 🔒 的字幕保持不动；规则冲突时会列出受影响词段与冲突条件，不会输出貌似完整的结果。

④ 确认导出

    每次确认生成一个不可变版本，可随时再次下载；后续修改不影响旧文件。

    ⑤ 批量修订提议（字幕）

    针对未锁定字幕一次提交一组修订，不直接改正正式字幕；预览核对后再整组采纳。 格式：{"note":"说明","items":[{"subtitle_id":1,"cue_version":1,"text":"替代文本","start_ms":0,"end_ms":1000}]} （时间可省略；空组、重复 ID、空文本、非法时间会被拒绝）

    ⑥ 逐词时间修正（词序/词文本不变）

    校对者发现逐词转写的时间偏差时，按词序号提交一组起止毫秒，携带读取时字幕集版本； 先预览受影响字幕与冲突，再确认。锁定字幕原样保留；仅受影响的未锁定区间重排， 未受影响字幕保留 ID/行版本/人工文本。 格式：{"note":"说明","sub_version":1,"items":[{"word_idx":0,"start_ms":0,"end_ms":480}]}

    提交只保存原值快照、不动正式词与字幕；预览通过后再确认（原子更新词时间+重排+推进版本）。

    ⑦ 多语言译文字幕

    译文沿用源字幕的起止时间与词区间，不改词、切点与原文；保存须带读取时行版本与译文版本。 源字幕文本/时间/词区间变化后译文转待复核；仅锁定或展示顺序变化不失效；重排删除的原行译文留作历史，新行视为缺译。

      导出前须当前每行都有有效当前译文且整版符合时间与切点约束，否则列出缺漏/冲突且不生成快照；已导出快照不可变。

      📖 译审术语对照表

      整表替换「源词 → 规定译法」，保存自动携带当前术语版本（未配置为 v0）。原文字幕精确命中源词时译文须包含规定译法（一行多词全部满足）；缺术语不阻止保存，但会阻止该语言导出/交付/译文署名导出，且不改变译文 current/review 状态。

      ⑧ 说话人标注与署名版导出

      维护说话人编号→显示名（改名推进归属版本）；按字幕 ID 归属，携带读取时行版本与归属版本，锁定行也可标注。 重排保留 ID 的行归属继续有效；原行删除后归属留作历史，新行待标注，不按展示序号转移。显示名不得含换行或 < >。

        署名版另存为不可变快照（WebVTT 说话人标签 <v 名称>…</v>）；普通导出与旧下载内容不变，原文与译文共用时间轴。

        ⑨ 逐词区间复核意见

        意见锚定导入代次 + 词序区间（不按字幕 ID/行号）：重排拆并、逐词改时、字幕行更替后仍显示在相交字幕旁。 创建自动携带当前导入代次与字幕集版本；区间须落在现有逐词转写内。关闭时保存相交字幕快照；其后文本/时间/词区间变化自动转待复核， 直到再次显式关闭；锁定或仅顺序变化不触发。重新导入后旧意见仅作历史查看、不可关闭。

        词序号见字幕列表每行「词 x–y」；创建/关闭/重新打开均带版本号，过期会返回当前值。
